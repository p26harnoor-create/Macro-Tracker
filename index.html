How to read this site

  • Every topic opens on a Summary; switch to Deep dive, Mechanism or Watch with the tabs, or hit Expand all in the sidebar to read straight through.
  • Links carry the tab: india.html#in-inflation/mech opens the inflation mechanism directly.
  • Fact statements are sourced at the bottom of each section. View statements are interpretation (ChatGPT's deep dive or mine) and should be argued with, not quoted.
  • To update: edit the HTML section, bump the dates in the hero, and adjust data/manual.json. The README has a Claude Code prompt for this.
